## 中盤への移行：防衛インフラの抜本的刷新

防衛の第3フェーズに入る頃には、木製のバリケードや原始的なスパイク（トゲ）トラップは、大型の肉食恐竜に対してほぼ無力化します。強烈な打撃を吸収するためには、強化石材や金属装甲プレートなどの強固な素材への移行が必須です。

サバイバル系コミュニティのプレイヤー経験則から見ても、第15ウェーブまでに外周リングを強化しておかなければ致命的な突破を許すことになります。太古の襲撃者たちは特定の装甲貫通力と攻城ダメージ倍率を持っているため、建材の硬度こそが第一の防衛線となります。

建築への投資効率を最適化するために、以下の基本的な耐久値指標を確認してください：

| 壁・防壁のティア | 基礎耐久力（HP） | ダメージ閾値 | 資源コスト（10mあたり） | 最適な使用箇所 |
| :--- | :--- | :--- | :--- | :--- |
| **強化木材** | 1,500 | 物理 10% 軽減 | 堅木 150、繊維 40 | 序盤の後退用レーン |
| **切り出し石板** | 4,200 | 物理/打撃 25% 軽減 | 石 300、モルタル 80 | 外周の境界壁 |
| **鉄筋コンクリート** | 11,500 | 全物理 50% 軽減 | コンクリート 250、鉄筋 120 | 主要なチョークポイント |
| **電撃通電メッシュ** | 8,000 | 物理 35% 軽減 / スタン効果 | 金属 150、電子部品 60 | 対空キルゾーン |

壁のアップグレードだけでは、俊敏な捕食者が防壁を飛び越えたりよじ登ったりするのを完全に防ぐことはできません。ねずみ返し（オーバーハング構造）の追加や二重の空堀ネットワークの構築は、現代の拠点工学における不可欠な要素です。生物の経路探索（パスファインディング）や空間建築システムの詳細な仕組みについては、[Unreal Engine Community Wiki](https://dev.epicgames.com/community/)の包括的なドキュメントを参照してください。

## 防衛チョークポイントと誘導（パス誘導）の操作

恐竜AIの経路探索は、最短経路アルゴリズムと障害物への抵抗検知に大きく依存しています。広大な外周全体を均等に守ろうとするのではなく、**build a dino defense part 3**のレイアウトでは、敵を専用のキルゾーンへと意図的に誘導すべきです。

「ファネル（漏斗）型」の構成を作成して恐竜の攻撃性を利用し、範囲攻撃（AoE）トラップが最大限のダメージを与えられる高密度の十字砲火地帯へアルファ級の捕食者を誘い込みます。

```
       [ 外周フェンス ]
          /           \
    [ 低い壁 ]     [ 低い壁 ]
         \             /
      [ ファネル・チョークポイント ]
      |   (スパイク / ガス)       |
      |                          |
    [ 自動タレット陣地 ]
```

### ファネルレーンに必須のトラップ連携

1. **減速からスタンへの連携：** キネティック・トリップワイヤーの直前にタールピットや粘着性の樹液プールを配置し、防衛火線の下で最大の接触時間を確保します。
2. **装甲劣化ゾーン：** 酸性ミスト噴霧器や腐食スパイクを活用して、敵がメインの防壁に達する前に分厚い鱗を削ぎ落とします。
3. **高所バリスタ：** 壁の後ろの高台に単体特化の重火砲を配置し、ブラキオサウルスやティラノサウルスなどの巨大ターゲットを狙い撃ちします。

| トラップ / 防衛システム | 有効射程 | ダメージ種別 | 特殊効果 | 弾薬 / 電力維持費 |
| :--- | :--- | :--- | :--- | :--- |
| **重バリスタ** | 65メートル | 貫通・攻城 | 敵2体を貫通 | スチールボルト 1本 / 発 |

## 恐竜の戦力化：生体ベースの拠点セキュリティ

純粋に機械だけに依存した要塞は、特に数ウェーブに及ぶ長期連戦で弾薬が枯渇した際、維持が困難になります。調教した恐竜を基地に組み込むことで、動的な防衛が可能な有機的戦力を編成できます。高体力のガーディアン恐竜と攻撃的な遊撃隊を組み合わせる戦術は、コミュニティでも高く評価されています。

体系的な**build a dino defense part 3**の設計図を用意する際は、恐竜同士が密集して射線を塞いでしまわないよう、明確な防衛ロールを割り当てましょう。

| 恐竜クラス | 主な役割 | 推奨される種族 | 最適なスタンス / 指示 | 装備 / 馬具・装甲 |
| :--- | :--- | :--- | :--- | :--- |
| **タンカー / アンカー** | 前線での引きつけ | アンキロサウルス / ステゴサウルス | 中立（ゲートに係留） | スパイク付きシェル装甲 |
| **遊撃 / インターセプター** | 高脅威ターゲットの迎撃 | ユタラプトル / デイノニクス | 攻撃的（パトロール範囲指定） | 鋸歯状の鉤爪 |
| **遠距離砲撃** | 飛行・攻城タイプの狙撃 | ディロフォサウルス変種 | タレットモード（高所に配置） | 毒腺増幅装置 |
| **ディスラプター** | 重型の押し返し | トリケラトプス / パキケファロサウルス | 防衛的（ゲートキーパー） | 強化角ブレース |

キルゾーンの入り口付近に装甲タンカーを配置して進行する捕食者の足を止め、俊敏なアタッカーを内庭で巡回させて外壁を突破した敵を迅速に排除します。

## 電力、自動化、物流管理

防衛が進展するにつれ、手動での弾薬補給や修理は現実的ではなくなります。自動化された物流ネットワークを構築することで、長時間の夜間襲撃でもタレットが弾切れを起こす心配がなくなります。

プレイヤーの検証により、電力ケーブルを地下に這わせて冗長性を持たせることで、外部発電機が破壊された際のシステム全停止を防げることが判明しています。

| 発電方式 | 燃料消費 | 基本出力 | 脆弱性要因 | 騒音プロファイル（敵の誘引） |
| :--- | :--- | :--- | :--- | :--- |
| **ディーゼル発電機** | 多（バイオ燃料/オイル） | 120 kW | 低（密閉型金属ハウジング） | 高（肉食恐竜を引き寄せる） |
| **地熱タービン** | なし（ノード依存） | 250 kW | 中（定位置配置） | 低 |
| **風力タービンアレイ** | なし（天候依存） | 40–90 kW | 高（露出した高所） | 無音 |
| **核分裂炉コア** | 極小（精製ロッド） | 800 kW | 致命的（爆発の危険あり） | 無音 |

収集した資源が貯蔵サイロの近くにある加工台へ自動で送られるよう、サプライチェーンを設計してください。自動コンベアや運搬ドローンを使用し、弾薬加工台から城壁沿いの防衛タワーへと弾薬を直接搬送します。

## ステップ別ブループリント：パート3防衛要塞の建設手順

体系的な建設手順に従うことで、インフラのアップグレード中に生じる脆弱性を防ぐことができます。適切な基礎を作らずに複雑な電気トラップへと急ぎすぎると、拠点を危険に晒すことになります。

1. **ステップ1：外周リングの拡張。** 中央司令部から最低でも半径60メートルのスペースを確保し、内側の後退用防壁を設置できる余白を残します。
2. **ステップ2：防衛用空堀の掘削。** 恐竜の移動頻度が高い回廊沿いに深い塹壕を掘り、突進してくる大型の敵を足止めします。
3. **ステップ3：ファネル回廊の建設。** 侵入経路を石壁で挟み込み、制御された2〜3箇所の侵入口へと絞り込みます。
4. **ステップ4：冗長電源グリッドの敷設。** 地下に電線管を通し、独立した局所バッテリーバンクを主発電プラントに接続します。
5. **ステップ5：生物用囲いの配置。** 防衛タレットの第一線の背後に飼育ケージを確保し、支援用恐竜を迅速に出撃させられるようにします。
6. **ステップ6：タレット陣地の要塞化。** 射線が重なり合う多層プラットフォームの上に、高ダメージのタレットを配置します。

```
       [ 司令ネクサス ]
              |
       [ 中央電源 ]
        /           \
  [ 弾薬庫 ]       [ 恐竜ケージ ]
        \           /
       [ 内郭要塞 ]
              |
     [ 防衛ファネル ]
```

この段階的なアプローチを実践することで、建設作業中も外周の防衛機能を損なうことなく安全を維持できます。

## よくある質問（FAQ）

### Build a Dino Defense パート3で最も多いミスは何ですか？
最も多い失敗は、弾薬の自動供給ラインを確立する前に外周を広げすぎてしまうことです。壁を広大にしすぎるとタレットの密度が薄まり、エリート級恐竜に手薄な箇所を各個撃破されて突破を許してしまいます。

### テイムした恐竜だけで自動タレットを完全に代用できますか？
訓練された恐竜は継戦能力が高く弾薬を消費しませんが、出血、毒、装甲破壊などの状態異常デバフに対して脆弱です。安定した遠距離火力を出す自動タレットと、前線で耐える頑丈な恐竜を組み合わせるのが理想的な構成です。

### 対空タレットが真っ先に破壊されるのを防ぐにはどうすればよいですか？
対空砲台の周囲を半壁や格子状の屋根で囲みましょう。上空への射線を確保しつつ、地上からの突進や低空からの毒唾攻撃から機材を遮蔽・保護することができます。

### 防衛レイアウトの点検・見直しはどのくらいの頻度で行うべきですか？
5〜10ウェーブごとに拠点の再点検を行ってください。敵AIのレベルが上昇すると、誘導回廊の最も脆い部分を学習して突いてくるため、定期的なトラップの再配置や壁の補強が必要になります。
