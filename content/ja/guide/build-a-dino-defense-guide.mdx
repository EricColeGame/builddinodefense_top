## 基本メカニクス：マージ、召喚、盤面エコノミー

防衛の基本は、エネルギーの生成、カスタムデッキからのカード引き、グリッドマスへのユニット配置、そして同一ユニットをマージしてティアパワーを強化するという、相互に連動したサイクルで成り立っています。このエコノミーを理解しておくことで、敵が密集するボスウェーブ中に息切れすることを防げます。

同じ星ティアの同一カードを2枚マージすると、1つ上のティアの圧倒的に強力な単一ユニットへと統合されます。しかし、闇雲なマージは初心者の戦術家が最も陥りやすい落とし穴です。マージを行うと、盤面の攻撃ユニットの総数が2体から1体へと減少します。時期尚早にマージしてしまうと、大群が押し寄せる直前に重要なクラウドコントロールやレーンへの攻撃範囲を失ってしまうリスクがあります。

```
カードドロー（エネルギー） ➔ 盤面配置 ➔ 戦略的マージ ➔ ティア倍率の上昇 ➔ ウェーブクリア
```

盤面のバランスを維持するために、「3ティアルール」を守りましょう。攻撃ユニットが不在となる無防備なレーンが生じてしまう場合は、前線を絶対にマージしてはいけません。フィールド上のユニットを強化する前に、十分な召喚ポイントを確保できているかを常に確認してください。

| コアシステム | 主要リソース | ベストプラクティス | よくあるミス |
| :--- | :--- | :--- | :--- |
| **召喚** | エネルギー / パワードロップ | 序盤からユニットを配置しレーンをカバーする | 敵が進軍しているのにエネルギーを溜め込む |
| **マージ** | 盤面の重複カード | 予備エネルギーが準備できている時のみマージする | 早期にマージして攻撃レーンを空けてしまう |
| **デッキ強化** | ゴールド ＆ カードシャード | まず主力のメインキャリーに育成を集中させる | 穴埋めカードに満遍なくリソースを分散させる |
| **アクティブスキル** | クールダウンタイマー | エリートやボスのHPが膨大な場面で発動する | 通常のザコ敵単体に大技スキルを無駄遣いする |

## 恐竜クラスの分類と役割のシナジー

バランスの取れたチームを作るには、異なるタイプのユニットが連携して機能する必要があります。単体攻撃に特化したユニットばかりで編成すると、足の速い大群に防衛線を突破されてしまいます。逆に、範囲攻撃だけに依存していると、高HPを誇る重量級のボスが登場した際に対処できなくなります。

### 1. 前衛タンク（ブロッカー ＆ アンカー）
圧倒的なHPと高い防御耐性を持つ恐竜です。敵の進軍ルートが交差する要所（チョークポイント）に配置します。例として、敵の進軍を遅らせる重装甲のケラトプス類やアンキロサウルス類が挙げられます。

### 2. 遠距離単体キャリー（ボスキラー）
素早い攻撃を繰り出す肉食恐竜で、先頭の敵に対して集中的な物理ダメージを高速で与えます。単体のタフな標的を素早く削る能力に長けていますが、数で圧倒されると押し切られてしまいます。

### 3. スプラッシュ・範囲攻撃（AoE）砲撃型
毒吐きや踏みつけを行う爬虫類のような長射程の攻城ユニットで、低HPの敵の群れを一掃します。単体キャリーがザコ敵の処理に無駄な攻撃手数を取られないようにサポートします。

### 4. サポート ＆ クラウドコントロール（CC）
氷結、スタン、ノックバック、被ダメージ増加デバフなどを付与するユニットです。的確に配置されたサポートユニットが1体いるだけで、部隊全体の実行火力を2倍以上に引き上げることができます。

| 恐竜クラス | 主な役割 | 理想のグリッド配置 | 相性の良いパートナー | 優先ターゲット |
| :--- | :--- | :--- | :--- | :--- |
| **前衛（タンク）** | 攻撃の吸収、敵の足止め | 1列目（チョークポイント） | 範囲砲撃型 | レーンの先頭ユニット |
| **ストライカー（単体DPS）** | ボスやエリートの撃破 | 2列目または3列目（直線状） | バッファー / デバッファー | 最も強い敵 |
| **ボンバーディエ（範囲攻撃）** | ザコ敵ウェーブの一掃 | 2列目（中央付近をカバー） | 前衛（タンク） | 最も密集している集団 |
| **妨害役（コントロール）** | スタン、減速、ノックバック | 1列目または2列目（側面） | ストライカー | 移動速度の速いユニット |
| **戦術家（サポート）** | 部隊の攻撃力/エネルギー強化 | 後衛（安全な角マス） | 周囲のすべての味方 | 味方オーラ |

## ステージ別攻略法：ウェーブとボスの撃破手順

戦場で戦略を実行に移すには規律が求められます。カードが使えるようになった瞬間に手当たり次第タップしてしまうと、盤面が散らかりタイルが無駄になります。戦況を完全に掌握するために、フェーズごとのロードマップに従いましょう。

| 試合フェーズ | 対象ウェーブ | 主な目標 | 戦略的アクション |
| :--- | :--- | :--- | :--- |
| **序盤フェーズ** | ウェーブ 1–3 | 盤面の基礎展開 | 主要レーンすべてに配置。マージは一切控える |
| **中盤フェーズ** | ウェーブ 4–7 | マージの統合とティア強化 | 低ティアの重複をマージ。範囲攻撃を展開する |
| **終盤フェーズ** | ウェーブ 8–10 | ティア3以上の強化とスキル発動 | キャリーの星数を最大化。バーストスキルを温存 |
| **ボスフェーズ** | 最終ウェーブ | 単体集中攻撃と取り巻きの足止め | 全火力をボスに集中。CCで進軍を食い止める |

### ステップ・バイ・ステップ戦術ワークフロー

1. **レーンアンカーの確立（ウェーブ 1）：** 片側のラインに偏らせるのではなく、各レーンに均等に基本ユニットを展開します。守りのないレーンを作ると、拠点へ即座にダメージが入ります。
2. **マージより展開を優先（ウェーブ 2–3）：** まずは盤面の空きマスを埋めます。ティア1のユニット5体は、ティア2のユニット2体よりも総DPSがはるかに高くなります。
3. **狙いすましたマージ（ウェーブ 4–5）：** 盤面が埋まったら、最も貢献度の低い重複カードをマージします。中央グリッド付近で最初のティア3 DPSキャリーを解放することを目指しましょう。
4. **クラウドコントロールの連携（ウェーブ 6–8）：** 防護シールドを持つエリート敵が出現したら、前線に到達する前にサポートスキルを発動して防御を剥がします。
5. **ボスの討伐（ウェーブ 9–10）：** 手動ターゲットでボスを狙い撃ちします。スタン効果などのCCスキルは同時に使うのではなく、ずらして発動させることで拘束時間を最大化します。

この**恐竜ディフェンス構築ガイド**の手法を実践することで、レーンの突破やボス戦での敗北を大幅に減らすことができます。

## 高度なカード強化優先順位とリソース配分

試合を重ねると、重複カード、ゴールド、強化トークンが貯まっていきます。これらのリソースを弱いカードに誤って投資してしまうと、攻略の進捗が大きく停滞します。投資対効果（ROI）を最大化するために、明確な優先順位を守りましょう。

```
メインキャリー（DPS） ➔ 主力前衛タンク ➔ 範囲攻撃スペシャリスト ➔ クラウドコントロール補助
```

常にメインのダメージキャリーの強化を最優先してください。アタッカーのステータス上昇率は非常に高く、各ウェーブのクリア時間を直接短縮してくれます。タンクのステータスも生存力に直結しますが、迫り来る敵を倒す火力がキャリーになければ、どれだけタンクのHPを増やしても耐えきれなくなります。

| 強化優先度 | ユニットの役割 | 優先度レベル | リソース配分比率 | ウェーブクリアへの影響 |
| :--- | :--- | :--- | :--- | :--- |
| **ティア 1** | 主力遠距離DPS | 最優先 | ゴールド/トークンの40% | ボス戦にかかる時間を約35%短縮 |
| **ティア 2** | 主力タンク | 高 | ゴールド/トークンの25% | 前線の維持時間を約30%延長 |
| **ティア 3** | サブ範囲攻撃（AoE） | 中 | ゴールド/トークンの20% | ザコ敵の大群による雪崩れ込みを防止 |
| **ティア 4** | CC ＆ スタン役 | 補助 | ゴールド/トークンの10% | デバフの持続時間を適度に延長 |
| **ティア 5** | 特定用途 / 穴埋め | 低 | ゴールド/トークンの5% | 序盤の影響は僅か。終盤まで温存推奨 |

## 回避すべき5つの致命的なミス

1. **予備リソース不足での過剰なマージ：** ティア1のユニットを2体マージすると、マスが1つ空きます。即座に新しいユニットを召喚するエネルギーがない場合、盤面の総合火力が一気に低下します。
2. **ルートの地形を無視した配置：** 射程の長いユニットの後ろに近接攻撃ユニットを配置すると、攻撃射程を無駄にしてしまいます。近接型は前方に、遠距離砲撃型は後方に配置してください。
3. **デッキシナジーの軽視：** 召喚コストが重いレジェンドカードばかりを5枚並べると、序盤のウェーブで安定性を大きく損ないます。高コストの強力ユニットと、低コストの使いやすいカードのバランスを取りましょう。
4. **ピンチ時のパニック召喚：** 敵が防衛線を突破しそうになった際、ランダムなマスに召喚を連打しても効果は薄いです。エネルギーを温存し、突破ルート上にピンポイントで強力なクラウドコントロールユニットを配置しましょう。
5. **クエスト報酬の放置：** ゲームのアップデートにより、デイリークエストや実績の目標が頻繁に追加されます。これらを忘れずに受け取り、召喚用通貨を安定して確保し続けましょう。

これらの戦術的ポイントを本**恐竜ディフェンス構築ガイド**と併せて見直すことで、急激な難易度の上昇にも柔軟に対応できる強靭な部隊を作り上げることができます。

## よくある質問（FAQ）

### 最初に強化すべき最も重要なカードは何ですか？
本**恐竜ディフェンス構築ガイド**では、主要な単体遠距離キャリーを最優先で強化することを強く推奨しています。メインキャリーの素のダメージを伸ばすことで、ウェーブクリアの速度が上がり、リソースの回収が早まるほか、高HPのエリート敵が前衛ブロッカーを突破するのを防ぐことができます。

### 戦闘中に恐竜をマージするベストなタイミングはいつですか？
マージを行うのは、盤面が完全に埋まっている時、または新しく空いたマスに即座に代わりのユニットを召喚できるだけのエネルギーが溜まっている時だけにしてください。マージすると攻撃の手数が減るため、エネルギーが枯渇した状態でマージすると隙が生まれ、足の速い敵に突破されやすくなります。

### 重装甲のボス恐竜はどうやって倒せばいいですか？
重装甲のボスを撃破するには、高ティアの単体キャリーに、装甲破砕（防御デバフ）や減速効果を持つサポートユニットを組み合わせます。スタンなどの妨害スキルを一度にすべて発動せず、タイミングをずらして連続で使用することで、ボスがキャリーの攻撃範囲内にとどまる時間を最大限に引き延ばしましょう。
