## ゲームの基本メカニクス：マージ、召喚、レーンコントロール

レーン型ダイナソーディフェンスゲームにおいて成功の鍵を握るのは、「カード収集」「戦場への召喚」「ユニット合成（マージ）」という相互に連動する3つのシステムです。低コストの基本ユニットでフィールドを埋め尽くすべきか、それらを高ティアの捕食者へと合体させるべきか、その見極めこそがカジュアルプレイと記録破りのクリアを分ける境界線となります。

```
[デッキプール] ---> (召喚コスト) ---> [戦闘フィールド]
                                           │
                                    (同名ユニット合成)
                                           ▼
                                [Tier 2+ 進化恐竜]
                                           │
                                  (レーン配置)
                                           ▼
                              [ウェーブ防衛 / ボス撃破]
```

### マージシステムの仕組み

フィールド上で同一の恐竜カード2枚をマージすると、盤面のスペースを節約できると同時に、攻撃力（ATK）、攻撃速度（ASP）、体力（HP）などのステータスが大きく上昇します。しかしプレイヤーの経験談からも明らかなように、早すぎるマージは初心者が最も陥りやすい罠です。レベル1のアタッカー2体をレベル2のアタッカー1体に合成すると、広いレーン全体での瞬間的な総DPS（秒間ダメージ）が低下し、敵の群れを取りこぼしてしまう原因になります。

| ユニットランク | 総DPS比率 | クラウドコントロール（妨害）効果 | 最適な盤面投入タイミング |
| :--- | :--- | :--- | :--- |
| **Tier 1 (基本)** | 100% (基準) | 低（単体ターゲット中心） | ウェーブ 1–5：レーン上の存在感を確立 |
| **Tier 2 (合成)** | 185% | 中（小規模な範囲攻撃/鈍足） | ウェーブ 6–12：前線の戦力強化 |
| **Tier 3 (頂点)** | 340% | 高（広範囲攻撃 / スタン） | ウェーブ 13–20：エリート敵への対抗 |
| **Tier 4 (神話)** | 620% | 卓越（画面全体の弱体化付与） | ウェーブ 20以降 ＆ ボス戦 |

カードを合成する前に、必ず進行中のレーン幅を確認してください。小型で移動速度の速い敵が自陣へ突撃してきている場合、Tier 2の強力な1体よりも、Tier 1を2体維持したほうが広い範囲をカバーできます。

## Build a Dino Defense 完全攻略：フェーズ別ガイド

エンドレスな防衛マップを進めるには、敵ウェーブの構成変化に合わせて経済状況と召喚の優先順位を柔軟に切り替える必要があります。序盤の立ち上がりから終盤の圧倒までを網羅した以下のステップバイステップガイドを参考にしてください。

### フェーズ 1：序盤の展開（ウェーブ 1–7）

開幕直後のウェーブにおける最優先目標は、盤面の制圧（枠の確保）です。スターター恐竜を焦ってマージしてはいけません。召喚可能なスロットをすべて埋め、足の速い敵が自陣へすり抜けないよう防衛ラインを構築しましょう。

1. **基本ディフェンダーの召喚：** 中央前列のグリッドに、最もコストの低い前線ユニットを配置します。
2. **敵ウェーブの特性を把握：** 出現する敵が飛行タイプか、それとも重装甲タイプかを確認します。
3. **マージは温存：** 物理ダメージの拡散を維持するため、この段階での合成はサポート系の重複ユニットのみに留めます。

### フェーズ 2：中盤の安定化（ウェーブ 8–15）

中盤に差し掛かると、重装甲の巨獣が出現し始め、レーンが枝分かれします。ここでは数の暴力だけでは厚い装甲を突破できないため、狙い澄ましたマージが不可欠になります。中盤のセットアップが甘いと一気に防衛線が崩壊するため、ここが本 **Build a Dino Defense 攻略** における最大の重要局面です。

| ステップ | 必要なアクション | 主な目的 | リソースの優先度 |
| :--- | :--- | :--- | :--- |
| **1. チョークポイント（要所）の構築** | タンク恐竜を狭い交差点へ移動 | 範囲攻撃を当てやすく敵を集約 | 肉 / エネルギー |
| **2. 狙い澄ましたマージ** | 後衛の遠距離アタッカーをTier 2へ進化 | 単体への貫通ダメージを増強 | 重複カード |
| **3. ユーティリティの配置**| 入口付近に鈍足・凍結持ちの恐竜を配置 | 足の速い敵の進軍を遅延 | 召喚シャード |
| **4. デッキの回転** | 低ティアの不要な重複カードを消費 | 主力ダメージディーラーを引き込む | エネルギー回復 |

### フェーズ 3：終盤およびボスウェーブ（ウェーブ 16以降）

ボスは膨大なHPを誇り、低ティアのユニット群を一撃で粉砕する壊滅的な範囲攻撃を仕掛けてきます。ボスを足止めしつつ攻撃を集中させるため、専用の鈍足エリアを維持しながら、盤面全体をTier 3およびTier 4のユニットへ移行させていきましょう。

```
敵の進行 ──> [減速ゾーン / 冷気恐竜] ──> [タンクライン / 頂点スピノ] ──> [後衛砲撃 / レックス] ──> 自陣
```

## 実践バトルテクニックとよくある失敗例

戦場での立ち回りを洗練させることで、より深いウェーブまで生き残れるようになります。防衛グリッドを敷く際は、以下の実戦的なコツを常に頭に入れておきましょう。

*   **「中央密集の罠」を避ける：** すべてのアタッカーを中央1マスに密集させると、両サイドの側道がおろそかになります。道幅全体をカバーできるよう、攻撃範囲が重なり合うように配置してください。
*   **突発的なウェーブに備えてエネルギーを温存：** 召喚エネルギーが貯まるたびに即座に使い果たすのは悪手です。足の速い敵が前線を突破してきた際に、緊急の壁役を即座に投下できるよう、一定のエネルギーを常にリザーブしておきましょう。
*   **ターゲット優先度の管理：** 手動でターゲットを指定できる場合は、移動の遅い大型タンクよりも、周囲の敵を強化するサポート役や遠距離攻撃を放ってくる厄介な敵を優先して排除します。
*   **属性とタイプ相性の活用：** 装甲を持つ甲虫や爬虫類の敵には、標準的な物理ダメージが軽減されてしまいます。ディロフォサウルスのような属性攻撃持ちや、装甲破壊に特化したユニットを最低1体はデッキに必ず組み込んでおきましょう。

この **Build a Dino Defense 攻略** で解説したテクニックを駆使すれば、どれほど獰猛な恐竜の大軍が押し寄せようとも拠点を守り抜くことができるはずです。様々な部隊のシナジーを試し、敵ウェーブの緩急に合わせて柔軟にマージを重ね、戦略的な判断力で戦況を支配してください。

## よくある質問（FAQ）

### Build a Dino Defense の攻略において最も効果的な初手は何ですか？
最もおすすめの初手は、メインレーンの交差点に低コストの近接型または群生型ユニットを2体配置し、その直後に遠距離アタッカーを配置する動きです。初期の召喚スロットがすべて埋まるまではユニットのマージを避け、序盤の大群ウェーブに対して盤面の攻撃カバー範囲を最大化しましょう。

### 高難度ウェーブで重複カードをマージすべきタイミングは？
マージを行うべきなのは、通常攻撃が通りにくい重装甲ユニットや高HPの中ボスが出現したタイミングに限られます。足の速い敵が広範囲に大群で押し寄せてきている場合は、合成して1体の強力なユニットを作るよりも、低ティアのユニットを複数並べてレーン全体の迎撃範囲を広げておく方が有効です。

### 終盤に登場する重装甲ボスはどう倒せばよいですか？
終盤のボスを撃破するには、ティラノサウルスのような装甲破壊ユニットと、トリケラトプスやディロフォサウルスのような妨害・遅延スペシャリストを組み合わせるのが基本です。チョークポイントでボスの進行を遅らせている間に、アタッカーで出血や装甲低下デバフを重ね掛けし、膨大なHPを一気に削り取りましょう。
